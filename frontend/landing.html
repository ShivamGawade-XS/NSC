// ANALYTICAL PIPELINE

From Raw Satellite Data
to Verified Evidence

A four-stage reproducible pipeline — every result is independently verifiable and CF-1.8 exportable.

STEP 01

Data Ingest

NASA POWER API fetch with 0.5° spatial resolution, daily temporal resolution, 2000–2023 temporal extent. Automatic unit normalization and gap-filling.

STEP 02

Trend Detection

Non-parametric Mann-Kendall test applied per cell, per variable. Sen's slope estimator for magnitude. Results stored in B-tree indexed SQLite cache.

STEP 03

FDR Correction

Benjamini-Hochberg procedure corrects for multiple comparisons across the full grid. Only cells with q<0.05 are flagged as statistically significant.

STEP 04

Visualization

Significant cells rendered on interactive Leaflet map. Time-series with Sen's slope line, anomaly bands, and correlation matrix — all exportable as NetCDF.
