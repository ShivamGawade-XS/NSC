# EarthSift — Scientific Methodology & Statistical Rigor

## 1. Principles of Earth-System Trend Detection

In environmental and climate science, trends cannot simply be calculated with Ordinary Least Squares (OLS) regression because Earth observation time series violate classical Gaussian assumptions:
1. **Non-Normal Distributions:** Environmental variables (precipitation, aerosol optical depth, surface reflectance) often feature skewed distributions or extreme events.
2. **Outliers:** Sensor anomalies, cloud contamination, and transient weather disturbances introduce non-physical spikes.
3. **Serial Autocorrelation:** Daily, monthly, or annual values exhibit memory, deflating variance estimates and yielding artificially low $p$-values.
4. **Spatial Multiplicity:** Evaluating thousands of grid cells across a map guarantees false positives if nominal significance thresholds ($p < 0.05$) are applied uncorrected.

To maintain scientific integrity, EarthSift adheres to established climate analysis protocols.

## 2. Statistical Methods

### 2.1 Trend Significance: Mann-Kendall Non-Parametric Test
The Mann-Kendall test assesses whether a monotonic upward or downward trend exists over time without requiring normality or linearity.

For a time series $X = \{x_1, x_2, \dots, x_n\}$:
1. **Test Statistic ($S$):**
   $$S = \sum_{k=1}^{n-1} \sum_{j=k+1}^n \text{sgn}(x_j - x_k)$$
   where:
   $$\text{sgn}(\theta) = \begin{cases} 1 & \text{if } \theta > 0 \\ 0 & \text{if } \theta = 0 \\ -1 & \text{if } \theta < 0 \end{cases}$$

2. **Variance of $S$:**
   $$\text{Var}(S) = \frac{n(n - 1)(2n + 5) - \sum_{i=1}^m t_i(t_i - 1)(2t_i + 5)}{18}$$
   where $m$ is the number of tied groups and $t_i$ is the number of data points in group $i$.

3. **Standardized Test Statistic ($Z$):**
   $$Z = \begin{cases} \frac{S - 1}{\sqrt{\text{Var}(S)}} & \text{if } S > 0 \\ 0 & \text{if } S = 0 \\ \frac{S + 1}{\sqrt{\text{Var}(S)}} & \text{if } S < 0 \end{cases}$$
   The two-tailed $p$-value is calculated from the standard normal distribution $\Phi(|Z|)$.

### 2.2 Trend Magnitude: Sen's Slope (Theil-Sen Estimator)
Rather than fitting an OLS line sensitive to single outliers, EarthSift employs Sen's slope estimator:
1. Compute slopes for all pairwise temporal combinations:
   $$Q_{k} = \frac{x_j - x_i}{j - i} \quad \text{for } 1 \le i < j \le n$$
2. The overall trend magnitude $\beta$ is the median of all pairwise slopes:
   $$\beta = \text{median}(Q)$$
3. Reported units are converted transparently (e.g., physical change per year or per decade) with documented conversion factors.

---

### 2.3 Multiple Comparisons: False Discovery Rate (FDR)
When testing $M$ individual grid cells across a region:
- At $\alpha = 0.05$, testing $10,000$ independent cells will falsely flag $\approx 500$ cells as "statistically significant" purely by chance.
- EarthSift applies the **Benjamini-Hochberg (BH)** procedure:
  1. Sort all calculated $p$-values in ascending order: $p_{(1)} \le p_{(2)} \le \dots \le p_{(M)}$.
  2. For a target false discovery rate $q^*$ (default $0.05$):
     $$k = \max \left\{ i : p_{(i)} \le \frac{i}{M} q^* \right\}$$
  3. Reject null hypotheses for all tests with $p \le p_{(k)}$.
- In the map interface, users can toggle between nominal $p$-value stippling and FDR-adjusted significance masks.

## 3. Data Integrity & Completeness

* **Minimum Sample Count:** Time series with $< 70\%$ valid observations over the selected duration are flagged with an "Insufficient Data" caveat and excluded from automatic signal ranking.
* **Temporal Aggregation:** To avoid seasonal aliasing (e.g., mistaking the cycle from summer to winter for a multi-year cooling trend), data are aggregated to annual means or deseasonalized prior to trend fitting.
* **Resolution Honesty:** Spatial visualizations display data at native grid resolution and explicitly disclaim artificial sub-grid interpolation.

---

## 4. Scientific Limits & Causality Disclosure

Every output generated by EarthSift includes an explicit scientific disclaimer:
* **Trend $\neq$ Causation:** Detecting a statistically significant warming or drying trend demonstrates empirical change, but does not identify physical mechanisms without multivariate modeling.
* **Period Dependence:** Trends are strictly valid for the analyzed time window. A positive 10-year trend may be part of a cyclical multi-decadal oscillation.
