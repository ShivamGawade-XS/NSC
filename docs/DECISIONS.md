# EarthSift — Architecture Decision Records (ADR)

| ID | Decision | Rationale | Alternatives Considered | Status |
| :--- | :--- | :--- | :--- | :---: |
| **ADR-001** | Use Mann-Kendall + Sen's Slope over Ordinary Least Squares (OLS) | OLS is distorted by environmental outliers and non-normal residuals. Sen's slope provides a robust median-of-slopes estimator with Gilbert (1987) non-parametric confidence intervals. | OLS linear regression, polynomial fitting | Accepted |
| **ADR-002** | Implement Benjamini-Hochberg (BH) False Discovery Rate at $\alpha = 0.05$ | Multi-pixel hypothesis testing across spatial grids inflates false alarms; BH monotonically controls expected false discovery proportion without the extreme conservatism of Bonferroni. | Bonferroni correction, Sidak correction, uncorrected $p$-values | Accepted |
| **ADR-003** | Decouple Data Adapter from Frontend | Prevents vendor lock-in to specific NASA endpoints; enables pluggable datasets (MERRA-2, NASA POWER, MODIS, CERES) and deterministic synthetic fixtures when offline. | Direct client-side NASA API fetching, monolithic server | Accepted |
| **ADR-004** | AI as Downstream Explainer, Not Calculator | LLMs hallucinate numerical statistics. All mathematical calculations are strictly deterministic; LLMs only interpret the verified, structured evidence record. | End-to-end LLM data analysis, LangChain agent calculators | Accepted |
| **ADR-005** | Leaflet 1.9.4 (Canvas Renderer) + Custom 3D HTML5 Orthographic Globe (`PlanetaryGlobe3D.jsx`) for Geospatial Visualization | Lightweight, zero-overhead 2D tile cartography with high-performance Canvas grid rendering, paired with a custom HTML5 Canvas 3D interactive orthographic globe, bypassing heavy WebGL runtime dependencies and vendor API keys while ensuring fluid 60 FPS interactions. | MapLibre GL JS, Mapbox GL JS, Google Maps API, CesiumJS | Accepted |
| **ADR-006** | Chart.js 4.5 for High-Performance Canvas Charting | Interactive canvas-rendered time-series charting with Sen's slope trendlines, Gilbert 95% confidence bounds, and changepoint annotations with minimal bundle footprint. | Apache ECharts, Plotly.js, D3.js | Accepted |
| **ADR-007** | React 19 + Vite 8 + Tailwind CSS v4 + Zustand 5 SPA with Web Worker Engine | Modern component hierarchy with atomic Zustand state, lightning-fast Vite 8 builds, CSS-first Tailwind v4 styling, and background Web Worker (`calcWorker.js`) offloading for heavy statistical transforms. | Zero-build Vanilla JS, Next.js, Redux Toolkit | Accepted |
| **ADR-008** | In-House Vectorized NumPy/SciPy Trend Engine over External Black-Box Packages | Vectorized upper-triangular array broadcasting (`np.triu_indices`, `np.nanmedian`, `stats.rankdata`) computes Sen's slopes and Hamed & Rao (1998) autocorrelation corrections orders of magnitude faster than iterative packages, with zero unvetted dependencies. | `pymannkendall`, `xclim`, `statsmodels` | Accepted |
